# AraújoIA

Site institucional da AraújoIA — sites, sistemas e soluções digitais.

Publicado em: [https://araujoia.netlify.app](https://araujoia.netlify.app)

## Stack

React + Vite + Tailwind CSS + Framer Motion.

## Local

```bash
cd araujoia
npm install
npm run dev
```

Abra [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Build / Netlify

```bash
npm run build
```

Publish directory: `araujoia/dist` (comando `npm install && npm run build` na pasta `araujoia`).
