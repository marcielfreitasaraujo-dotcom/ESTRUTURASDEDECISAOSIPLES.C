# ADR 002 — Prisma 6 em vez de Prisma 7/8

Status: aceito  
Data: 2026-09-09

## Contexto

Prisma 8 é o lançamento atual. Better Auth ainda gera schema no formato Prisma 6 e declara peer dependency estreita. Prisma 7 move `DATABASE_URL` para `prisma.config.ts` e exige driver adapter.

## Decisão

Prisma ORM 6.19 + `prisma-client-js` clássico. Upgrade planejado quando o CLI/adapter do Better Auth for compatível sem workaround.

## Consequências

Não usamos a API de “contracts” do Prisma 8. Migrations SQL padrão em `prisma/migrations`.
